# FICTIONAL — Torque Dynamics: Technician Hiring Configuration (Mexico)

*Synthetic sample data. Approved by customer project lead.*

Torque Dynamics hires Manufacturing Technicians at its Monterrey plant.

### Stage configuration
| Order | Stage | Owner |
|---|---|---|
| 1 | Application Review | Recruiter |
| 2 | Recruiter Screen | Recruiter |
| 3 | Aptitude Test | Recruiter |
| 4 | Supervisor Interview | Production Supervisor |
| 5 | Medical Exam | Plant HR Manager |
| 6 | Background Check | Plant HR Manager |
| 7 | Offer | Plant HR Manager |

### Roles
- Recruiter: screens applicants.
- Production Supervisor: is the hiring manager.
- Plant HR Manager: owns checks and offers.

### Approvals
- Requisitions require approval from the Plant Manager and Finance.
