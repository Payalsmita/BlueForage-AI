# FICTIONAL — Urban Threads: Retail Associate Hiring Configuration

*Synthetic sample data. Approved by customer project lead.*

Urban Threads is a fashion retailer hiring Sales Associates, including seasonal hires.

### Stage configuration
| Order | Stage | Owner |
|---|---|---|
| 1 | Online Application | HR Coordinator |
| 2 | Text-Message Pre-Screen | HR Coordinator |
| 3 | Group Interview | Store Manager |
| 4 | Store Manager Interview | Store Manager |
| 5 | Offer | Store Manager |
| 6 | Background Check | HR Coordinator |

Stage details:
- Text-Message Pre-Screen: Automated text conversation that checks availability.
- Background Check: Run after the offer; the offer is contingent on it.

### Roles
- Store Manager: is the hiring manager.
- District Manager: approves exceptions.
- HR Coordinator: owns background checks.

### Approvals
- Starting pay above the standard rate requires District Manager approval.
- Seasonal requisitions above the store's seasonal headcount plan require District Manager approval.
